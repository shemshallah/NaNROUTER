# Round 043 — native associative byte memory

**Status:** external C++20/PyTorch experiment with native 8 MiB cache storage.
Not a fluent model and not evidence of a unique geometric prediction advantage.
Archive SHA-256:
`2cc23a1a5239908f18fe0e52b3e32088e08f5d6f662684192a07336626445b33`.
Machine-readable record: `spec/round043-associative-memory.v1.json`.

## What was run

A frozen SO(72) byte language model is augmented with a 3-byte → 32-way
next-byte associative cache stored in the native 8 MiB cycle root.

```text
cache rows       4096
trained rows     3968
reserved rows     128
lanes              32
context length      3 bytes
contexts seen   13,577
training bytes 2,265,053
```

The cache is learned from training-text frequency counts and mixed with the
frozen model by a validation-selected interpolation weight. It is not the
learned multi-hop graph reasoner and it is not end-to-end trained.

## Results

Three seeds, 1,404 held-out WordNet entries, **124,996 target bytes/model**.

| Model | Mean nats/byte |
|---|---:|
| No memory | **1.744586** |
| Native 3-byte cache | **1.645717** |

The reduction is **5.67%**. The matched conventional flat cache matches the
native result within a few millionths of a nat per byte, so the gain belongs to
the memory augmentation, not uniquely to native geometry.

Other measurements:

- post-gauge write/delete/restore max error **1.29e-5**;
- gauge maximum observable drift **1.29e-5**;
- an unseen online 3-byte context moved from **0.0** to **0.953869** conditional
  probability and survived an exact root snapshot;
- shuffled-cache loss rose to **2.146–2.339** nats/byte;
- Alice excerpt improved slightly but is a single out-of-domain diagnostic;
- deleting the 80 most frequent contexts was non-monotone and could slightly
  improve one seed;
- generated byte samples remain largely incoherent.

## Native additions

| Kernel | Role |
|---|---|
| `mth.byte.assoc3_reserve.u32` | Deterministic 3-byte context → one of 128 reserved rows; collisions expected |
| `mth.byte.memory_mix256.f32` | `(1-w)*base + w*memory` per byte probability, atomic preflight |

The reserve hash is address mapping only. The mix is a probability
interpolation, not a learned gate.

## What this establishes

- Persistent native associative memory can improve a frozen byte model's
  held-out loss on this restricted corpus.
- Post-gauge writes, deletion, restoration, and snapshots work.
- A previously unseen 3-byte context can be stored in a reserved row.
- The conventional cache ties native numerically.

## Non-claims

- No NaN-bit or quantum advantage.
- The flat cache ties the native cache.
- Generated language is not fluent.
- The cache is not the multi-hop graph reasoner.
- The Alice excerpt is not broad generalization.
- No live deployment or production model.
